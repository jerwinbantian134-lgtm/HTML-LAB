HTML Text Formatting

HTML stands for HyperText Markup Language.

Below is an explanation of each text formatting tag.

Tag Explanations

<b> - Bold

The <b> tag makes text bold without adding extra importance. Example: This is bold text.

<strong> - Strong Importance

The <strong> tag shows that text is very important. Browsers display it as bold.

<i> - Italic

The <i> tag makes text italic, such as a technical term or a thought.

<em> - Emphasis

The <em> tag emphasizes text. Browsers display it in italics.

<u> - Underline

The <u> tag adds an underline to text.

<mark> - Highlight

The <mark> tag highlights text, like a highlighter pen.

<small> - Small Text

The <small> tag makes text smaller, often used for fine print.

<del> - Deleted Text

The <del> tag shows text that was removed: old price: $100.

<ins> - Inserted Text

The <ins> tag shows text that was added: new price: $80.

<sub> - Subscript

The <sub> tag lowers text below the line, as in H2O.

<sup> - Superscript

The <sup> tag raises text above the line, as in 102.
